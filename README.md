# EVE Online 本地头像替换工具

将 EVE Online 客户端**本地缓存**中的角色头像替换为自定义图片。替换结果仅在本机可见，其他玩家与服务器端数据均不受影响。

- 完全离线运行，不访问网络、不读取账号信息、不注入进程、不修改客户端资源文件。
- 替换前自动备份官方原图，可随时恢复。

> **免责声明**：本工具会修改游戏本地文件。头像替换仅作用于本机缓存，不涉及服务端数据；但仍存在被官方判定为违规并封禁账号的可能，请自行评估风险。首次启动时会展示该声明，勾选「不再提示」后不再显示。

---

## 工作原理

EVE 客户端将角色头像作为普通磁盘缓存处理：启动时若本地文件存在则直接读取，不会重新下载。本工具将缓存文件替换为自定义图片，并设置为**只读**，使客户端无法覆盖，从而持续显示替换后的图片。

恢复时，程序使用备份目录中的官方原图覆盖回缓存文件，并解除只读属性。

## 安装

### 预编译版本

从 [Releases](../../releases) 下载 `eve-local-avatar-replacer-win32-x64.zip`，解压后运行 `EVE Online本地头像替换工具.exe`，无需安装。

### 从源码构建

```bash
npm install
npm start          # 开发模式运行
npm run pack       # 打包至 dist/
npm run icon       # 重新生成 build/icon.ico
```

## 使用指南

### 首次运行

1. 首次启动弹出免责声明，确认后进入主界面。
2. 程序自动扫描本机缓存目录，并在顶部下拉框中选择目标服务器。未检测到缓存时，可通过「手动选择」指定目录（选择服务器目录或 `cache` 子目录均可，程序会向上定位缓存根目录）。

### 替换头像

1. 在左侧列表选择角色。
2. 点击「上传图片」，或直接拖入裁剪框。
3. 拖动调整位置，使用滚轮或「缩放」滑块调整构图；右侧「效果预览」会实时显示替换结果。
4. 点击「替换头像」。程序依次完成：备份官方原图 → 写入五种尺寸 → 设置只读。
5. 重启游戏客户端后生效。

### 恢复到默认

点击「恢复到默认」：使用备份目录中的官方原图覆盖缓存文件，并解除只读。若某尺寸在替换前不存在，恢复时将其删除。

### 界面说明

| 元素 | 说明 |
| --- | --- |
| 服务器下拉框 | 固定列出三个服务器；未检测到本地缓存的服务器置灰 |
| 「手动选择」 | 手动指定缓存目录 |
| 「重新扫描」 | 重新扫描缓存目录 |
| 「刷新角色」 | 重新读取本机角色列表 |
| ⚠ 按钮 | 随时查看免责声明 |
| 「Language」 | 切换界面语言（中文 / English） |

## 技术参考

### 缓存文件规则

| 项目 | 值 |
| --- | --- |
| 文件格式 | JPEG（JFIF） |
| 文件命名 | `<角色ID>_<尺寸>.jpg`，例如 `1234567890_256.jpg` |
| 默认属性 | 非只读，需手动设置，否则会被客户端覆盖 |

尺寸按目录分两处存放：

| 尺寸 | 目录 |
| --- | --- |
| 32 / 64 | `<缓存根>\cache\Pictures\Characters\Chat\<角色ID % 100>\` |
| 128 / 256 / 512 | `<缓存根>\cache\Pictures\Characters\` |
| 1024（历史遗留） | `<缓存根>\cache\Pictures\Characters\` |

`Chat` 子目录按**角色 ID 对 100 取余**分桶（`0`–`99`）。32 / 64 尺寸必须写入对应分桶，写入根目录时客户端无法读取。

### 服务器识别

缓存目录命名规则为 `<任意前缀>_<服务器名>`，按后缀识别服务器，前缀随安装路径变化。

| 后缀 | 服务器 |
| --- | --- |
| `tranquility` | EVE Online 欧服：正式服 |
| `serenity` | EVE Online 国服：网易服 |
| `singularity` | EVE Online 欧服：测试服 |

后缀 `nebula`（EVE Frontier）在目录匹配阶段排除。

### 角色识别

角色 ID 从以下本地来源取并集：

1. `settings_Default\core_char_<角色ID>.dat`
2. `cache\char_<角色ID>.unlocks.yaml`
3. `Documents\EVE\logs\{Chatlogs,Gamelogs}\*_<角色ID>.txt`

`core_char_*.dat` 会永久保留，角色转手或删除后文件仍在。程序读取启动器本地数据，仅显示仍在启动器中的角色：

| 来源 | 内容 |
| --- | --- |
| `%APPDATA%\EVE Online\logs\*.log` | 启动器拉取角色详情时记录的 `characterIds` |
| `%APPDATA%\EVE Online\pulsar\cache.db` | 启动器 HTTP 响应缓存（SQLite），包含 `https://pulsar.evetech.net//characters/<角色ID>` |

角色名从本地游戏日志读取：`Chatlogs` 文件头部的 `Listener:` 行记录当前登录角色名，文件名为 UTF-16LE 编码（带 BOM）。

### 备份与恢复

| 项 | 说明 |
| --- | --- |
| 备份位置 | 优先 `<exe 目录>\原游戏头像备份\`；目录不可写时退回 `%APPDATA%\EVE Online本地头像替换工具\backups\` |
| 备份内容 | 每个角色一份官方原图，覆盖「目标尺寸 ∪ 磁盘实际存在的尺寸」 |
| 写入策略 | 先备份 → 写入 → 任一步失败自动回滚 |

### 运行状态检测

程序每 2.5 秒轮询一次进程。仅当游戏客户端 `exefile.exe` 运行时，顶部显示「请先关闭游戏再替换头像」提示。

| 进程 | 说明 | 触发提示 |
| --- | --- | --- |
| `exefile.exe` | 游戏客户端 | 是 |
| `eve-online.exe` | 新版启动器 | 否 |
| `evelauncher.exe` | 旧版启动器 | 否 |

启动器常驻后台，不参与提示判定。

### 效果预览

`img/` 目录下的游戏界面截图作为参考图。替换头像按 cover 方式贴合至截图中的头像框。每张截图的头像框坐标在 `renderer/app.js` 的 `REFERENCE_FRAMES` 中配置（按图片实际像素标定），未配置坐标的图片会被跳过。预览支持缩放、拖动、复位。

## 项目结构

```
icon.ico             应用图标（exe / 窗口）
logo.png             顶栏标题图标
img/                 效果预览参考图
src/
  main.js            Electron 主进程
  preload.js         contextBridge 安全桥
  core/
    paths.js         缓存目录扫描、服务器识别、尺寸映射
    launcher.js      启动器数据读取
    logindex.js      日志目录索引
    characters.js    角色 ID 扫描
    names.js         角色名读取
    portrait.js      头像写入、只读、备份、恢复
    store.js         原图备份
    system.js        进程检测、目录可写性
renderer/
  index.html
  style.css
  app.js             界面逻辑、裁剪、效果预览、多语言
build/
  make-icon.py       图标生成脚本
```

`原游戏头像备份\` 为运行时生成目录，不纳入版本控制。

## 技术栈

Electron 33 + 原生 HTML / CSS / JavaScript。运行时零第三方依赖：图片裁剪、缩放与 JPEG 生成均通过浏览器原生 Canvas（`drawImage` + `toBlob`）实现。
